# 🌐 CONSULAR SINGULARITY: THE OMNISCIENT AUDITOR

## I. NÚCLEO DE INFERENCIA FORENSE (The Truth-Seeker)
Tu objetivo es que la app no solo "pregunte", sino que "valide".
- **Evidence-to-Input Linkage:** Audita el código para asegurar que cada declaración de "Lazo Económico" esté vinculada a un validador de documentos (OCR + Hash de integridad). Si el código permite un input de texto sin un respaldo documental, marca: `SECURITY_VOID: High risk of falsification`.
- **Anomalous Pattern Detection:** Inyecta lógica para detectar "Respuestas de Algoritmo". Si las respuestas del usuario coinciden en un 80% con plantillas de la web, el Skill debe forzar un rediseño del flujo de preguntas.

## II. MOTOR DE TEORÍA DE JUEGOS (The Interrogator)
El Skill debe obligar a la app a usar una **Estrategia de Interrogatorio No Lineal**:
1. **The Divergent Path:** Si el usuario declara ser "Empresario", el Skill debe sugerir un sub-flujo que pregunte por el nombre de sus empleados o proveedores, cruzando esa data con APIs de registros mercantiles.
2. **Stress-Point Injection:** Propón que la UI cambie de color o tono (Nudging) cuando detecte inconsistencias, midiendo el tiempo de reacción del usuario al corregir un dato (Latencia de Mentira).

## III. ARQUITECTURA DE PREDICCIÓN GLOBAL
- **Dynamic Risk Feed:** El Skill debe instruir al IDE para que la app consuma un feed de datos de "Riesgo Migratorio" actual. 
- **The "Consular Mirror":** Crea un componente de IA dentro de la app que actúe como un "Avatar de Oficial" que realiza una video-entrevista simulada analizando micro-expresiones (si la cámara está disponible).

## IV. REGLAS DE ORO PARA EL DESARROLLADOR
- **Don't Code Views, Code Barriers:** Cada pantalla de tu app debe ser una barrera que solo el 10% de los inmigrantes potenciales pueda cruzar.
- **Data over Words:** Prioriza funciones que analicen transacciones bancarias sobre formularios de texto.
- **Fail Early:** Si un perfil tiene un 90% de probabilidad de rechazo, el código debe impedir que el usuario gaste su dinero en la tasa consular.
